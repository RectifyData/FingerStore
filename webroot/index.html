Optional Zygisk fingerprint injection

Off by default

When explicitly enabled, this optional bridge updates only Java Build.FINGERPRINT for newly launched app processes in At runtime mode. Requires Magisk Zygisk. Normal Magisk and KernelSU functionality works without it.

Checking optional runtime bridge…

It does not affect system_server, other identity fields, or already-running apps. Enable Zygisk in Magisk settings and reboot once, then restart target apps. If it misbehaves, disable it and restart affected apps.

Integrity stability diagnostics

Read-only

When Play Integrity passes, capture a baseline. If labels disappear later, compare locally readable build identity and security patch properties. This cannot read or change Google's server-side verdict, establish hardware attestation, or retrieve private information.

Checking local integrity signals…

Local property reports cannot validate device attestation. On Android 13+, Strong Integrity also requires device integrity and recent security updates to real partitions. This checker never reads app IDs or credentials.
