# Built-in fingerprint data: sources, scope and verification

FingerStore v1.4.7 combines five sources for **two different purposes**: exact firmware fingerprints and firmware discovery. The installable WebUI contains an **offline snapshot** generated by `scripts/refresh_catalog.py`. As of the initial November 2026 snapshot it contains **524 device profiles with 1,098 literal fingerprint entries (1,082 distinct fingerprint strings)**, including Android 13, 14, 15, 16 and 17. Counts can change on a future refresh.

## Sources

| Source | Role | Import policy |
| --- | --- | --- |
| [MagiskHide Props Config](https://github.com/Magisk-Modules-Repo/MagiskHidePropsConf/blob/master/common/prints.sh) | Historical multi-brand stock-fingerprint list | All structurally valid `user/release-keys` records from `PRINTSV=137`, not just the earlier 100-device subset |
| [DeviceAnon profiles](https://github.com/UYIYUIYUIYUIJ/DeviceAnon/blob/main/app/src/main/assets/profiles.json) | Community profiles covering many Android generations | Exact source fingerprint only, with its declared version, model and patch; deduplicate exact matches |
| [Pixel-Props/build.prop releases](https://github.com/Pixel-Props/build.prop/releases) | Extracted official Pixel OTA property bundles | Read the *actual* `system.prop` inside recent release ZIPs, prefer its recorded product/system build fingerprint, model, patch and date. Never infer a fingerprint from the ZIP filename |
| [ChkDumps](https://github.com/ChkDumps) | Firmware dump cross-reference, including newer Xiaomi and Tecno builds | Read real dump build.prop from each repository's **actual default branch**. Only import a distinct complete *global* `ro.build.fingerprint` when present; do **not** present generic `missi` system or older vendor-partition fingerprints as the device's full build |
| [Android Flash Index](https://github.com/TsinbeiLabs/android-flash-index) | Google factory/OTA build URLs and device discovery | Link official downloadable images as references. **Build IDs and image URLs are not fingerprints** and cannot be used to manufacture one |

The historical source is MIT licensed (Didgeridoohan, 2018–2021). DeviceAnon is MIT licensed (FinSec Lab). Pixel-Props tooling is GPL-3.0; FingerStore does not copy that project's executable code, but records literal property values from its publicly released OTA-derived packages with links to the source. ChkDumps and Google's image metadata are cited as reference facts; no proprietary firmware binaries are repackaged.

The historical input is [`common/prints.sh`](https://github.com/Magisk-Modules-Repo/MagiskHidePropsConf/blob/master/common/prints.sh), revision `PRINTSV=137`, source Git blob `dbddef20bea59e12290b936eb751ed74d38456b0`. DeviceAnon source Git blob: `063439d9dc26f4b495d3e514af56a1ecbf5623cb`. The initial snapshot incorporates **328 new Pixel-Props fingerprints** from all 52 available release collections (a few repeated assets are deduplicated), not merely the latest monthly release. Pixel OTA assets are cited by their specific immutable release asset URLs in each catalog record.

## Authenticity policy

A **literal stock fingerprint** is not a freshly verified *OEM certification*. The historical and DeviceAnon lists are community-maintained and can be wrong, region-specific or superseded. Pixel-Props packages are derived from OTA image extraction, but FingerStore does not independently audit each image or Google's remote attestation.

- Each imported build keeps the original `brand/product/device:release/build-id/incremental:user/release-keys` string. The Android version selector lists only versions genuinely present in the source.
- Multiple real builds of the same Android version are retained under **Recorded firmware build** instead of discarded or synthesized.
- A source-reported security patch is used as a patch field only; it never becomes an invented fingerprint or timestamp.
- When the exact build UTC date is present in extracted firmware properties, the UI uses that day. When missing, **Apply selected** uses the fingerprint-only `epoch=-` mode, preserving the device's original build date rather than inventing one. That existing date might not match the stock build, and the UI says so. Users may instead fill a verified date in the Editor. Patch dates are **not** substituted.
- Partition fingerprints (vendor, system, product) can legitimately disagree with the global build fingerprint on upgraded OEM firmware. They appear as verification/discovery references only when a usable global build cannot be established.
- Source names, original asset URLs and per-build provenance are included in the offline catalog. Data is not silently downloaded by the installed Magisk/KernelSU module.
- No Play Integrity, SafetyNet, CTS, hardware attestation or device-boot success is claimed by this list.

To check a build on matching stock firmware:

```sh
adb shell getprop ro.build.fingerprint
adb shell getprop ro.product.model
adb shell getprop ro.build.version.security_patch
adb shell getprop ro.build.date.utc
```

For Pixels 6 and newer, see Google's [Pixel Binary Transparency](https://developers.google.com/android/binary_transparency/pixel_overview). Be aware that the Google Flash Index covers build metadata and images, not global fingerprints directly.

## Refreshing

On a connected host with Python 3:

```sh
python3 scripts/refresh_catalog.py --output webroot/catalog.js
node --check webroot/catalog.js
node tests/test_catalog.cjs
node tests/test_catalog_webui.cjs
```

The separate GitHub Actions **Refresh FingerStore built-in fingerprint catalog** workflow automates collection and commits a new checked offline snapshot on its requested branch. Official installable releases still require the normal PR, validation and release workflow. The importer fails closed if the core historical list, DeviceAnon input, or current Pixel OTA bundles are unavailable/invalid. No network connection is required to browse the already installed catalog.

The ChkDumps and Flash Index entries are pointers to **firmware sources**, not additional fictitious spoofable fingerprints.
